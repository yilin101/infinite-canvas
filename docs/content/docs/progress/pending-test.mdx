# 待测试

- 生图工作台：参考图区域新增手绘入口，可打开画板绘制线稿，并将画板内容保存为参考图参与图生图。
- 无限画布：底部工具栏新增手绘参考入口，可用多色画笔在白底画板绘制线稿并作为图片节点加入画布，连接到生图节点后参与图生图参考。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 图片节点快捷工具：新增“上传图床”按钮，点击后上传当前图片到 `https://amzimg.bizzlife.top/api/v1/upload` 并复制返回链接。
- 二开维护：新增同步原项目的 GitHub Action、个人 GHCR 镜像发布配置、宝塔服务器 Docker Compose 和维护文档。
- 图床配置：上传接口、请求方法、字段名和 Bearer Token 改为 Docker 环境变量配置；网页配置中新增图床根域名，未设置根域名时阻止上传并引导到图床设置。
- 图床返回链接：图床根域名只需填写 `brp2o0stwv.xin`，上传成功后自动生成 `http://随机4位.m.brp2o0stwv.xin` 并替换图床返回链接的域名。
- 图床上传：默认上传地址改为 `https://amzimg.bizzlife.top/api/v1/upload`，上传代理会保留 POST 跟随跳转，并在 405 时提示实际请求地址，方便检查宝塔里的 `IMAGE_HOST_UPLOAD_URL`。
- 账号管理：默认启用登录后才能使用，账号密码由 Docker 环境变量配置；登录后自动应用服务器默认 API 配置、模型和图像生成参数，并支持顶部账号菜单退出。
- 默认 API 配置同步：新增 `APP_DEFAULT_CONFIG_VERSION`，服务器默认 API 地址、Key 或模型配置更新后，提升该版本号即可让已登录用户下次打开网页自动同步新默认配置。
- 默认生成设置：配置弹窗的“生成偏好”新增默认图像质量、尺寸、工作台张数和画布张数设置，可看到并调整 Docker 下发的默认值。
- iPad 画布操作：新增鼠标 / 触控 / Pencil 输入模式切换，触控设备默认 Pencil 模式；支持手指平移、双指缩放、Pencil 拖动节点，并放大触控下的缩放和连线热区。
- iPad 画布稳定性：优化触控移动时的全局事件监听、pointer capture 容错和节点长按菜单，减少偶发失灵与卡顿。
